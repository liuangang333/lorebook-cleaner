# 世界书随卡清理（SillyTavern 扩展）

删除角色卡时，顺手清理它绑定的世界书（lorebook / World Info）。

## 行为

删除角色卡后，扩展会读取卡片的 `data.extensions.world`，然后扫描所有角色卡：

- **没有其他卡引用这本世界书** → 弹窗询问「是否同时删除世界书」，点「删除世界书」才会删。
- **还有别的卡在用** → 默认跳过，只弹一条 warning 提示（可在设置里改成仍然询问）。
- **卡片没有绑定独立世界书**（或世界书内嵌在卡片里）→ 不做任何处理。

删除前会检查共享引用，不会误删被多张卡共用的世界书。**不做备份**，删除不可恢复。

## 安装

### 方式一：酒馆内从 URL 安装（推荐）

1. 打开酒馆 → 「扩展」面板 → 「安装扩展 / Install Extension」
2. 粘贴本仓库地址（HTTPS）：

   ```
   https://github.com/<你的用户名>/lorebook-cleaner
   ```

3. 安装完成后刷新页面。扩展列表里会出现「世界书随卡清理」。

仓库名会决定安装后的文件夹名；用 `.git` 结尾的地址也可以。

### 方式二：手动放置

把本仓库文件放进以下任一目录，然后刷新酒馆页面：

- 全局：`public/scripts/extensions/third-party/lorebook-cleaner/`
- 当前用户：`data/<用户名>/extensions/lorebook-cleaner/`

## 设置

「扩展」面板 → 「世界书随卡清理」：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 删除角色卡时，询问是否删除它绑定的世界书 | 开 | 总开关 |
| 每次删除前弹窗确认 | 开 | 关掉则无确认直接删 |
| 世界书仍被其他角色卡使用时，直接跳过 | 开 | 关掉则改为弹窗，可选择仍然删除 |

## 兼容性

- 需要 SillyTavern 1.19+（依赖 `CHARACTER_DELETED` 事件与 `/api/worldinfo/delete` 接口）。
- 只处理角色卡「绑定」的独立世界书文件；卡内内嵌（`character_book`）的世界书随 PNG 一起消失，无需处理。

## 卸载

「扩展」面板里关闭或删除该扩展，或直接删掉扩展文件夹。
